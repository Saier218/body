# 0006 界面框架

- 状态：生效，2026-11-22 落地（React 19.1.10，构建插件 @vitejs/plugin-react 6.2.1）
- 日期：2026-11-16

## 结论

正式界面使用 **React + TypeScript**，构建工具沿用 Vite。3D 核心不依赖 React，通过一个薄封装组件接入。

## 理由

| 选项 | 评价 |
|---|---|
| **React** | 采用。生态和资料最多，类型支持成熟，与 Capacitor 配合常见。对由 AI 协作开发的项目，主流意味着出错更少、日后招人或外包更容易 |
| Vue | 国内同样流行，能力相当。没有选它只因为团队协作方（AI）在 React 上更稳，两者差距不大 |
| Svelte / Solid | 更轻，但生态小，遇到问题可查的资料少 |
| 不用框架 | 目前一个页面可以，页面一多，状态与导航会难以维护 |

## 约束

- 界面文字一律走文字表；医学内容一律来自内容数据。
- 不引入大型组件库。组件按选定的视觉方向自建，保证质感一致，也避免授权和体积问题。
- 路由、状态管理等库在第一次真正需要时再选，届时各写一条决策记录。
