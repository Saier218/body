# 0011 首屏改为全身概览

- 状态：**方向已定，形式待定**
- 日期：2026-11-22
- 取代：决策 0010 第 1 条（"打开 App 直接进入手部"）。0010 中左手默认、左右手镜像、竖屏以外的其余内容继续有效。

## 已定

- 首屏是人体全身概览，点部位逐层深入（负责人决定，回到最初的产品设想）。
- 层级尽量少，保证细节可达的前提下保持简洁。
- 手机锁定竖屏（iPhone 与安卓手机；iPad 保留横竖屏，因为 iPad 应用锁方向会失去分屏能力）。
  安卓 16 起，面向 API 36 的应用在大屏设备（平板、折叠屏展开）上的方向锁定会被系统忽略。此为据已有知识，未逐条核实。

## 待定（见调研 `docs/design/research/2026-11-22-entry-and-navigation.md`）

1. 全身概览用 3D 还是 2D 正反面图。开发推荐 3D。
2. 全身模型的外观：骨骼加浅层肌肉、中性人体模型，还是皮肤模型。开发推荐骨骼加浅层肌肉，皮肤模型含生殖器细节，不适合。
3. 是否去掉面包屑，改为返回按钮加部位名称。开发推荐去掉。
4. 左右手是否由在全身上点的位置决定，部位页保留开关。开发推荐如此。

已做好的手部页面不作废，它就是第 2 层"部位"页。
