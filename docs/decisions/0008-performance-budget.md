# 0008 性能预算

- 状态：生效（数值为初始设定，拿到真机数据后校准）
- 日期：2026-11-16

## 结论

以下上限由 `npm run budget` 自动检查，超出即构建失败。要提高上限必须改这份记录并说明原因。

| 指标 | 上限 | 当前 | 设定依据 |
|---|---|---|---|
| 启动时加载的 JavaScript（压缩后） | 250 KB | 124 KB | 当前的两倍，为界面框架留余量 |
| 单个分区的模型文件 | 3 MB | 1.83 MB | 三个分区合计不超过约 10 MB |
| 同屏三角面数 | 150,000 | 117,480 | 中低端手机的保守估计，**未经真机验证** |
| 同屏绘制次数 | 150 | 103 | 每个结构一次；超过后需合并同类网格 |
| 内容数据包 | 500 KB | 约 40 KB | 文字数据，留足余量 |

## 待真机校准的目标（尚无自动检查）

- 中低端安卓机上旋转模型不低于 30 帧/秒
- 从点开 App 到看到模型不超过 3 秒

## 说明

- 三角面数与帧率的关系因机型差异很大，上述数值是起点，不是结论。验证页里的"跑性能测试"按钮就是为校准准备的。
- 肩部分区加入后，三个分区不会同时显示，按分区加载。
