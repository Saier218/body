# 0002 伤病日志的存储方式

- 状态：生效
- 日期：2026-11-15

## 结论

第一版伤病日志只存在用户手机本地，并提供导出与导入。云同步作为后续版本，不在第一版范围内。

## 理由

- 伤病记录是敏感个人信息。上传到服务器就要做单独同意、安全措施、删除与导出机制，审核风险也更高（准则 3.3）。
- 这个功能是否有人用还没有验证，不应先付出云端的合规成本。

## 已知代价与缓解

- 用户删除小程序或换手机会丢失记录。缓解：在记录第三条日志时提醒一次备份，导出文件可存到微信聊天或文件中，换机后导入。
- 存储读写集中在一个模块后面，页面不直接调用存储接口。日后加云同步只需替换这个模块并做一次旧数据迁移。
