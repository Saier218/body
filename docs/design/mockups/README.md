# 视觉方向样稿（两选一）

日期：2026-11-16。用浏览器打开 `index.html` 可并排看两个方向；`shots/` 里是 390×844（2 倍像素）的截图。

这是**静态样稿**（纯 HTML/CSS，无 JS、无框架、无网络字体、无外部链接），用来选方向，不是 App 代码。选定后，把对应的 `tokens.css` 搬进 App 作为设计变量（design tokens，即"颜色、间距、圆角、字号的统一取值表"）。

## 两个方向的想法

**A · 临床冷静 / Clinical calm**（`a/`）
像一台测量仪器：深色底，3D 模型铺满上半屏当主角；全页只有一个冷色（青蓝）做强调，唯一的暖色留给"请尽快就医"。靠 1px 细线分层、不用阴影；圆角小（2–12px）；正文 14px，信息密；小标签和数据用等宽字体；图标线条细（1.5px、直角端点）。

**B · 岩馆暖调 / Chalk & warm**（`b/`）
像岩馆里一张镁粉味的指南卡：暖色纸感底，内容装在浮起的大圆角卡片里（16–28px），靠柔和阴影分层、不用细线；正文 16px、标题 30px 加粗，留白多；一个陶土橙强调色（取自岩点），主按钮用墨色而不用橙色，避免和警示红混在一起；图标线条粗（2.1px、圆头），常放在圆形色块里；底部标签栏是悬浮的胶囊。

除颜色外的差异：字号阶梯、密度、圆角、卡片/面板处理、图标粗细、分级时间线的形式（A 是条形刻度，B 是步骤圆点）、分段切换的形式（A 是方格加下划线，B 是胶囊滑块）。

## 各自的已知弱点

**A**
- 深色加等宽小字，容易显得"冷"和"专业门槛高"，对新手不够亲切；户外强光下深色屏可读性差。
- 11px 的小标签虽然过了对比度，但对视力一般的人偏小；中文用等宽栈时会回落到系统默认字体，中英混排字宽不齐。
- 细线分层在低端安卓屏上可能发虚。
- 警示块是全页唯一暖色，够醒目；但如果以后别处也想用红/橙，就会削弱它。

**B**
- 密度低：同样一屏，动作列表只露出 4 条半（A 能露出 5 条还有余）；损伤页比 A 长约 18%。
- 橙色强调与深红警示同属暖色，靠"墨色主按钮 + 警示块整块实心"拉开，但色觉障碍用户区分度仍弱于 A。
- 浅色视口里，米色骨骼与暖灰背景的反差比深色视口小，3D 的"主角感"弱于 A；视口底色必须保持比骨骼色深。
- 阴影与大圆角在低端机上有渲染成本（量级小，但需按性能预算实测）。
- 卡片套卡片的结构，内容一多容易显得"碎"。

**两者共同**
- 3D 图上的 A2 标注圈是手工对位的静态图，真实 App 里要由 3D 引擎算位置。
- 只做了中文；英文版标题更长，需另验排版。
- 没做深浅模式切换；选定方向后是否提供另一种模式，另行决定。

## 我的建议：选 A 作为基础，吸收 B 的两点

理由：

1. **产品的核心是 3D 解剖。** 模型的红、米、蓝三色在深色底上分得很开，在暖色浅底上米色骨骼会发闷。A 让模型当主角，B 让卡片当主角。
2. **"就医警示"在 A 里更突出。** A 全页只有它是暖色；B 里它要和橙色强调争注意力。
3. **可信度。** 这是健康相关的科普，A 的克制更接近"参考资料"，不容易被误读成营销页（对应准则 3.2）。
4. **密度。** 损伤页内容长，同样内容 A 的页面短约 15%（2137px 对 2529px）。

但 A 的亲和力不足是真问题，建议落地时从 B 借两样：正文从 14px 提到 15px（当前原型也是 15px）；小标签下限从 11px 提到 12px。这样仍是一套 token，只改 `a/tokens.css` 里的两三个数。

不确定之处：目标用户里新手占多少我没有数据。如果首发主要面向刚入门的馆内爱好者，B 的亲和力可能比上面几条更重要——这点需要产品负责人判断，或者拿这两张图找 5 位岩友看一眼再定。
