# 架构总览

一句话：**内容是数据，3D 是一个可替换的显示部件，平台只是外壳。** 这三者分开，任何一个变化都不牵动另外两个。

## 分层

```
┌──────────────────────────────────────────────────────────────┐
│ 原生外壳              ios/  android/  （Capacitor 生成）      │
│   只负责把下面的界面装进一个 App，不写业务逻辑                │
├──────────────────────────────────────────────────────────────┤
│ 界面（React，网页技术）apps/app                               │
│   页面、文字、触摸事件、读模型文件、设计变量、本地存储        │
├──────────────────────────────────────────────────────────────┤
│ 3D 核心（平台无关）   packages/viewer-core                    │
│   渲染、相机、点选、分区聚焦、图层开关                        │
├──────────────────────────────────────────────────────────────┤
│ 内容（纯数据）        content/  结构、动作、损伤、来源        │
│   每个结构一个稳定编号，模型与内容靠这个编号对应              │
├──────────────────────────────────────────────────────────────┤
│ 流水线（离线运行）    tools/modeling                          │
│   原始模型 → 全身概览 / 取分区 → 补建结构 → 打包 → 目录文件   │
└──────────────────────────────────────────────────────────────┘
```

同一份 `apps/app` 有三种运行方式：在浏览器里（开发和自动测试用）、在 iOS 外壳里、在 Android 外壳里。
`apps/miniprogram` 是冻结的小程序外壳，不再维护（决策 0004）。

## 数据怎么流动

1. **离线**：流水线读取 BodyParts3D 原始模型和文献参数，产出两个文件：模型（几何形状）和目录（每个结构的编号、中英文名、类别、所属分区）。
2. **运行时**：界面读取这两个文件交给 3D 核心。核心只认编号，不认识任何医学内容。
3. **交互**：用户点击 → 界面把触摸坐标交给核心 → 核心算出点中了哪个编号 → 界面用编号去内容数据里查名称、相关动作和损伤并显示。

## 贯穿全局的约定

| 约定 | 为什么 |
|---|---|
| 结构编号是唯一的连接点 | 模型可以重做、内容可以重写，只要编号不变就互不影响 |
| 核心只依赖画布的 5 个成员 | 换平台时只需重写薄薄的一层界面适配（这次从小程序换到 App 就是这样做的） |
| 医学内容不写在代码里 | 可以逐条核对来源、单独下线有误条目 |
| 每条数据带来源与状态 | 合规和可信度的基础（准则第 5 节） |
| 界面文字全部走文字表 | 中英双语从第一天成立 |
| 用户数据读写集中在一个模块 | 本地存储日后可换成云同步（决策 0002） |
| 颜色只在设计变量里定义一次 | 界面色标与 3D 材质由同一份 `tokens.css` 驱动（决策 0009） |
| 模型只存右手，左手实时镜像 | 一份数据、一份内容，左右两侧永远一致（决策 0010） |
| 两种模型：全身概览与部位精细模型 | 概览只用来选部位，按部位合并简化；进入部位再换精细模型。哪些部位有内容由 `content/regions.json` 决定（决策 0011） |

## 质量关口

一条命令全跑：`npm run check`。每次推送后 GitHub 也会自动跑一遍（`.github/workflows/check.yml`）。

| 关口 | 拦什么 |
|---|---|
| 代码规范（lint） | 写法问题；3D 核心里出现任何平台专有的全局对象 |
| 类型检查 | 类型错误；核心单独用"不含浏览器类型"的配置再查一遍 |
| 协议检查 | 依赖里出现允许清单之外的开源协议 |
| 内容校验 | 缺来源、缺危险信号、禁用措辞、模型与内容对不上等（决策 0005） |
| 性能预算 | 代码体积、模型大小、面数、绘制次数超限（决策 0008） |
| 端到端测试 | 在模拟手机触屏的浏览器里真实操作 App |

另有两项按需运行：`npm run test:contract`（核心脱离浏览器运行）和 `tools/modeling/run.sh`（从原始数据重建全部模型）。
