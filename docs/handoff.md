1. **仓库是公开的。** 负责人已决定改为私有（2026-11-22），需本人在 GitHub 网页操作。
2. **A2 样例没有标成"已对照来源"。** 准则 3.5 规定 AI 生成的医学内容必须经人工对照来源才能发布。这条内容是 AI 助手读论文后写的，引句做过机器核对（88 条全部在原文中找到），但没有人看过。所以它是草稿，打包时会被剔除。需要你或那位康复科医生朋友对照 `docs/evidence/` 过一遍，之后把状态改为 `sourced` 并填审阅日期。
3. **没有用 `bodyapp` 仓库。** 小程序和 App 共用同一个 3D 核心和同一份内容，拆成两个仓库会让这两样东西各存一份并逐渐走样。它们留在一个仓库的不同文件夹里（`apps/app` 与 `apps/miniprogram`）更稳妥。`bodyapp` 可以删掉或留空。
4. **视觉方向**：已选 A（决策 0009）。
5. **安装包没有上过真机。** 编译通过只说明工程配置正确，3D 在真机上能否流畅显示仍未验证。

## A2 样例过程中的发现

- 最常被引用的 Schöffl 分级原文不是开放获取，我们只读到别的综述对它的转述。条目里已如实写明。
- 没有找到任何正式的共识或指南，只有一份尚未出结果的专家共识研究方案。
- 文献里没有现成的"危险信号清单"，条目里的清单是根据"何时需要影像或专科评估"归纳的，这一步是编辑判断，最需要医生把关。
- 不同文献的数字不一致，例如 2 级的恢复时间有 6–8 周和 8–10 周两种说法，条目里两个都列了。
- 对青少年有一条重要信息：骨骼未成熟者滑车断裂少见，更常见的是生长板应力性损伤，表现为近指间关节背侧疼痛。已写进危险信号。
- 这条内容没有配动作条目。"全握"涉及哪些肌肉需要另外的文献，今晚没有做。

## 已知问题清单

- 10 个交叉或斜行滑车的网格不封闭，渲染无碍，做剖切效果前要修。
- 交叉滑车的条带宽度是为了看清而选的，没有文献依据。
- 原始数据中一块右手肌肉被标为"左"，暂标"来源标签待核对"。
- BodyParts3D 压缩包内文件头仍写旧协议，建议发邮件请对方书面确认（决策 0001）。
- 应用标识、名称、图标都是占位。
- 英文禁用词按词根匹配，可能误伤正常用词。
- 伤病日志只有设计，没有代码（决策 0007）。
- 3D 核心的 `focusGroup` 仅为冻结的小程序保留，App 使用 `focus`。
- 代码检查里没有 React 专用的规则插件，Hook 用法错误只能靠测试发现。
- Vite 提示配置文件的加载方式将来会变，目前不影响构建。
