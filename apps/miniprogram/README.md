# 小程序外壳

> **重要：这里的一切都还没有在微信里运行过。** 代码只通过了类型检查和包体大小检查；开发环境里没有微信开发者工具，也没有手机。你明天在开发者工具里打开时，是它第一次真正运行。出问题是正常的，把看到的情况发回来即可。

## 这是什么

这是同一个产品的**小程序版外壳**，和 App 并行（决策 0012）。它和 App 共用三样东西：

- **3D 核心**：显示和操作 3D 人体的那部分程序，App 和小程序用的是同一份；
- **内容**：部位、结构、名称等数据，同一份；
- **设计**：颜色、字号、间距照搬 App 的设计（方向 A，决策 0009）。

只有"外壳"不同：页面怎么排、按钮怎么画、文件怎么读，按小程序的规矩重写了一遍。行为尽量和 App 一致：全身概览 → 点亮色部位飞进去 → 点结构看卡片。

## 在 Windows 电脑上打开（一步步）

1. **下载开发者工具**：搜索"微信开发者工具"，进入微信官方文档网站（developers.weixin.qq.com）的下载页，选"稳定版 Windows 64 位"，安装后用微信扫码登录。
2. **导入项目**：点"导入"，目录选这个文件夹 `apps/miniprogram`。**不要选整个仓库的根目录**，否则工具找不到小程序。
3. **AppID**：在模拟器里试，选"测试号"即可。
   - 想在**真手机**上看，需要一个真正的 AppID。你有公司主体，可以在微信公众平台（mp.weixin.qq.com）用公司主体注册一个新的小程序，拿到 AppID 后在"详情 → 基本信息"里换上。注册和后续的备案、类目，上线前要另外对照官方当前规定核实（准则 3.4）。
4. **打开硬件加速**：菜单"设置 → 通用设置"，勾选"开启硬件加速"。不开的话 3D 可能很卡或者显示不出来。
5. **基础库版本**：右上角"详情 → 本地设置 → 调试基础库"，选 3.0 以上（项目里默认填的是 3.5.8；如果列表里没有这个版本，选列表里最新的 3.x 即可）。
6. 点"编译"。左边的手机模拟器里应该出现深色界面和一个 3D 人体。
7. **在手机上看**：用"预览"生成二维码，用手机微信扫码。**不要用"真机调试"**：据此前查到的资料，WebGL（网页 3D 绘图技术）在"真机调试"模式下不能用（未在本项目中验证）。

## 请按这个顺序试一遍

1. **全身**：进来先看到全身人体。手、前臂是亮色，其余是灰色。单指拖动旋转，双指缩放和平移。
2. **点灰色部位**（比如大腿）：底部应提示"该部位的内容正在整理中"。
3. **点亮色的前臂或手**：镜头先朝那里飞一下（约 0.4 秒），然后换成精细的手部模型。标题变成"左手"或"右手"，取决于你点的是哪一侧。
4. **左右开关**：右上角的"左 / 右"开关，点一下切到另一只手，停在同一个位置和角度。
5. **点一个滑车**（手指上的蓝色小环）：底部出现结构卡片，镜头推近那根手指。点卡片右上角的 × 关闭。
6. **图层**：画面底部的"骨骼 / 肌肉与肌腱 / 筋膜 / 滑车"按钮，点一下隐藏或显示这一层。
7. **列表**：左上角"列表"按钮。在全身页列出所有部位，在手部页列出当前范围内的所有结构，点一项就在 3D 里选中它。
8. **返回**：左上角"‹ 全身"回到全身。全身页右上角的圆形箭头是"复位"，让人体回到正面。
9. **我的**：切到底部"我的"标签。试一下中文 / English 切换（底部标签文字也应跟着变）。
10. **性能测试**：在"我的"页最下面一栏点"运行性能测试"。它会自动跳回身体页并转动模型约 4 秒；转完后请自己切回"我的"页，结果会出现在按钮下面。

## 请发回来

- **"我的"页最下面那一栏文字的截图**（性能测试按钮下面那几行英文）。里面有基础库版本、设备型号、画布大小、3D 版本、帧率，最有用。最好模拟器和手机各一张。

- 如果开发者工具底部的"调试器 → Console"里有红色报错，也截一张。

## 给开发者的说明

- 页面：`pages/body`（身体，核心）、`pages/moves` 与 `pages/injuries`（占位）、`pages/me`（我的）。公共代码在 `utils/`，全部样式在 `app.wxss`（从 App 的 `tokens.css` 与 `app.css` 移植，改动时两边同步）。模型颜色另见 `utils/tokens.ts`。
- `libs/`、`models/`、`content/` 是构建产物，**不要手改**。在仓库根目录运行 `npm run build:miniprogram` 重新生成，它会顺带检查主包是否在 2 MB 以内。
- 界面文字全部来自共享文字表 `packages/shared`（经 `libs/shared.js`），页面里不写死任何语言。唯一的例外是 `app.json` 里标签栏的初始文字（配置文件不能调用翻译），每个标签页显示时会立即按当前语言改写。
